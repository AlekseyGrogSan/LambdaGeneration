# **Lambda Generation** 💡

**Веб-приложение, позволяющее пользователям публиковать и просматривать статьи на различные научные, образовательные и просто интересные темы. Каждый пользователь может написать собственную статью, лайкать, комментировать чужие и делиться ими, а также подписываться на интересных ему авторов. Сайт будет полезен всем, кто хочет поделиться своим опытом и навыками или узнать что-то новое.**

---

## 🛠 Стек технологий

* **Backend:** ASP.NET Core (.NET)
  * База данных: PostgreSQL
* **Frontend:** React (JavaScript)
  * UI/UX: Material-UI (MUI)

## 📖 Руководство пользователя (Инструкция по сайту)

Добро пожаловать в **Lambda Generation**! Здесь вы можете читать увлекательные материалы, делиться своими знаниями и находить единомышленников. Вот краткая инструкция по основным функциям платформы:

### ✍️ Создание собственной статьи
Делитесь своими идеями с миром всего в несколько кликов:
1. Авторизуйтесь на сайте и нажмите кнопку **«Опубликовать»** (или иконку создания поста).
2. Заполните форму статьи:
   * **Заголовок:** Придумайте цепляющее название.
   * **Превью:** Краткое описание, которое привлечет читателей.
   * **Основной текст:** Раскройте тему полностью.
   * **Теги:** Выберите до 5 подходящих тегов для удобного поиска.
3. Убедитесь, что всё выглядит отлично, и нажмите **«Опубликовать»**. Ваш пост готов! 🎉

### 📚 Чтение и взаимодействие
* **Лента:** На главной странице собраны самые свежие и популярные статьи. 
* **Оценки:** Понравилась статья? Поставьте лайк ❤️, чтобы поддержать автора.
* **Комментарии:** Обсуждайте прочитанное! Оставляйте комментарии 💬 под статьями и общайтесь с другими пользователями.
* **Поделиться:** Нашли что-то классное? Поделитесь ссылкой с друзьями 🔗.

### 👤 Профиль и подписки
* **Настройка профиля:** Заполните информацию о себе и загрузите аватар, чтобы стать узнаваемым в сообществе.
* **Подписки:** Читаете крутого автора? Подпишитесь на него 🔔, чтобы не пропустить новые статьи в своей персональной ленте.

*Присоединяйтесь к нашему сообществу и развивайтесь вместе с [Lambda Generation!](https://lambda-gen.ru/)* 🚀
